# IndustrialProtocolDemo V19.4 验证报告

## 版本目标

V19.4针对两个现场问题进行升级：

1. 编辑生成方案后，右侧提示仍保留初始生成状态；
2. 价格目标搜索遗漏防护等级、枚举和布尔等后置属性，导致人工可达的低价方案未被生成器发现。

## 实现结果

### 当前草稿完整重评估

方案属性修改后，前端等待约500毫秒自动提交当前草稿。后端重新计算并返回：

- 预测价格及区间；
- 效能、效费比和可行概率；
- 当前标签及标签判定依据；
- 用户需求未满足项；
- 耦合与明确工程约束；
- 模型经验轮廓；
- 训练域异常、外推风险和预测可信度；
- 当前调整建议。

前端使用请求序号丢弃过期响应，避免连续输入时旧结果覆盖最新结果。“初始生成来源”仅用于追溯，不再作为当前风险提示的数据源。

### 混合属性合法域

统一支持五类自动搜索属性：

- 连续数值；
- 整数数值；
- 有序离散；
- 无序枚举；
- 布尔开关。

防护等级从旧版“历史出现值列表”改为整数工程域54～68。IP64等历史协议未出现但工程范围允许的等级可以参与编辑、生成、校验和模型计算。

### 价格等输出目标主动搜索

生成器会对全部允许自动调整的属性执行轻量单步敏感度扫描，而不是只检查显示顺序靠前的数值属性。离散、枚举和布尔属性会枚举合法邻居；有效调整会继续进入逐项和双属性协同搜索。多个候选均满足目标时，优先保留改动幅度较小的方案。

### 规则严重程度

- “错误”级明确工程规则：作为硬约束并允许自动修复；
- “警告”和“提示”级关系：只显示风险，不再强制覆盖用户编辑值或生成参数。

## 兼容性与限制

- 模型契约保持3.0，不需要重新训练模型即可升级程序。
- 安全补丁不覆盖数据库、模型、DataMaster、备份、上传文件和日志。
- 首次启动会自动迁移数据库搜索类型。
- 价格低于目标只表示模型预测满足条件。外推程度较高或可信度较低的候选仍需专家审核、仿真或试验验证。
