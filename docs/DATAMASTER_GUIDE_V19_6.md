# V19.6 DataMaster维护指南

工作簿增加`填写说明`和`字典_下拉项`，总计10张工作表。所有固定类型字段均提供Excel下拉列表；标签编号、指标编号等引用字段也使用动态下拉。

对于新成品，优先在“待发布成品 → 从历史成品表自动建立草稿”上传普通 CSV/XLSX，不必先手工维护下拉字典。空单元格和指定的 `-1`、`\`、`/` 等符号会被识别为缺失；任一行缺失的属性先标为非必填。系统对含义明确的 0/1 推断为有/无，对含义不明确的 0/1 保留枚举并标记人工确认。

自动草稿下载的维护工作簿会额外包含第11张`自动推断报告`，用于复核原始列、推断类型、缺失数和置信状态。该报告只供说明，回导时不会作为业务模块提交。部分单元格为空仍可切换业务数据；只有点击价格/效能计算时，目标HTTP服务才处理其必填字段。

关键区分：

- “取值类型=布尔”说明字段类型；历史协议和标签规则中的实际布尔值填写“有/无”。
- “搜索类型=布尔开关”说明智能生成时以开关方式切换。
- 连续数值适用于质量、速度等；整数数值适用于数量和整数等级；有序离散适用于档位；无序枚举适用于材料；布尔开关适用于功能有无。
- 允许值仅用于枚举/离散属性，连续和布尔字段通常留空。
- 模型字段绑定只服务于计算侧诊断/配置，不参与业务数据导入、检查和切换。

模板保留“模型字段绑定”工作表是为了兼容计算配置和现场诊断；它可以为空，也不会成为回导或切换业务数据的门槛。
