# V19.3变更记录

1. 删除生成器对用户锁定属性的可行轮廓强制回投。
2. 新增用户技术条件优先投影与全流程锁定。
3. 新增反向轮廓有限差分补偿搜索。
4. 新增单属性、双属性和相关联合邻域。
5. 新增多起点束搜索与逐轮缩小步长。
6. 显式耦合和硬约束修复不再覆盖用户锁定值。
7. 用户需求满足但位于经验范围外时，继续计算价格和效能，并显示外推风险。
8. 前端将“需求未满足”和“模型外推”分开显示。
9. 详情页将可行轮廓改称“模型经验区间”，并说明用户值不会自动回调。
10. 保留V19.1的DataMaster、静默预生成、来源分离、Cloudflare登录只读和宽表导入功能。
