# IndustrialProtocolDemo V19.3 验证报告

验证日期：2026-07-27

## 1. 本轮目标

本轮针对V19.1把模型经验轮廓当作强制回投边界的问题，重构方案生成算法。

新的原则是：

- 用户明确筛选的技术属性先投影并锁定；
- 学习得到的可行轮廓只作为历史经验参考、补偿方向和可信度依据；
- 轮廓、显式耦合和约束处理不得静默覆盖用户锁定值；
- 即使方案处于历史范围之外，也继续计算价格、效能和可行概率；
- 外推风险、工程硬冲突和用户条件未满足必须分别显示。

随包模型与数据仍为虚拟演示数据，不代表真实工程结论。

## 2. 新生成算法

算法名称：

```text
demand_anchored_reverse_contour_adaptive_neighborhood_search
```

中文说明：需求锚定、反向轮廓补偿、自适应迭代邻域搜索。

流程：

1. 根据标签、技术指标和模型输出目标选择多个相似且互相有差异的历史种子；
2. 将AND模式下可直接表达的用户技术条件投影到种子，并锁定这些属性；
3. 计算锁定属性相对于模型经验轮廓的偏离；
4. 对轮廓模型源属性执行有限差分，识别能够缩小偏离的补偿方向；
5. 同时生成单属性、双属性联动和局部相关联合邻域；
6. 执行DataMaster显式耦合及硬约束修复，但不修改用户锁定值；
7. 对每个候选调用价格、效能、可行概率和异常检测；
8. 按工程硬冲突、用户需求偏差、轮廓偏离、异常程度、模型结果和修改距离进行词典序比较；
9. 将较优且具有差异的候选保留为下一轮搜索中心；
10. 逐轮缩小搜索步长并返回最终方案。

## 3. 关键行为验证

### 3.1 用户属性不会被轮廓覆盖

自动测试设置：

```text
质量上限 = 10.000 kg
```

结果：所有生成候选均保持质量为10.000 kg，生成轨迹将`mass_kg`记录在`locked_parameters`中。后续轮廓补偿、耦合修复和多轮邻域搜索均未修改该值。

### 3.2 历史经验范围外仍然计算

测试构造了一组明显超出经验轮廓的需求：

```text
质量上限 = 5.000 kg
额定推力 = 18000 N
行程 = 220 mm
盐雾时间 = 240 h
工作温度下限 = -60 ℃
工作温度上限 = 100 ℃
```

确定性测试结果：

- 质量保持：5.000 kg；
- 模型质量经验区间：19.636～22.000 kg；
- 低于经验下限：14.636 kg；
- 预测价格：22.7734万元；
- 效能分：79.1713；
- 可行概率：0.129810；
- 预测可信度：低；
- 方案类型：探索方案；
- 搜索评估候选：260个；
- 搜索轮次：2轮。

系统没有把质量拉回19.636～22.000 kg，而是保留用户目标、继续执行双模型计算，并明确记录外推偏离及工程风险。

### 3.3 外推与需求未满足分开

生成结果区分：

- `满足条件`：满足用户条件且主要处于模型经验范围内；
- `需求满足·外推评估`：满足用户条件，但存在经验轮廓或训练域外推；
- `探索方案`：仍有用户条件或明确工程硬规则未满足。

外推本身不再自动判定为“生成失败”。

## 6. 边界说明

V19.3能够对历史覆盖范围之外的参数组合执行模型外推，但外推结果的可靠性取决于真实训练数据和模型结构。软件会显示可信度和偏离原因，不能将低可信探索方案直接视为已验证的工程可实施方案。正式应用仍需结合仿真、试验、制造能力和专家审核。
