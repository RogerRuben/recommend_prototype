# 基于筛选条件的需求锚定生成

## 技术属性条件

AND模式下能够转换为参数边界的筛选条件会在历史种子上优先投影，并在后续搜索中锁定。

例如：

```text
质量上限 ≤ 10 kg
额定推力 ≥ 12000 N
自诊断 = 有
```

最相似历史方案会先调整到满足这些条件。可行轮廓、相关扰动和耦合修复不能把这些属性改回历史经验区间。

## 输出条件

价格、效能、效费比和可行概率需要在每个候选调用双模型后检查。它们参与邻域中心更新，而不是只在搜索结束时过滤。

## 模型经验轮廓

经验轮廓用于：

- 衡量外推程度；
- 判断预测可信度；
- 搜索其他属性的补偿方向；
- 生成风险提示。

经验轮廓不再作为用户目标属性的强制回投边界。

## OR条件

OR条件无法安全合并成一个联合参数盒，因此主要在模型评价后复核。生成器仍会根据最相似历史种子与各分支距离进行搜索。

## 无严格方案

系统仍会返回模型可计算的新方案，并分别标明：

- 用户条件未满足；
- 明确工程硬规则冲突；
- 历史经验轮廓外推；
- 模型训练域异常。

这些状态不会混为同一个“不可行”。
