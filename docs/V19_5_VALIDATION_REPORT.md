## 2. 价格／效能字段角色

运行时根据两个模型字段集合自动计算：

```text
共享属性 = 效能字段 ∩ 价格字段
效能专用 = 效能字段 - 价格字段
价格专用 = 价格字段 - 效能字段
```

验证结果：

- 同一字段可以同时保存价格和效能两条绑定；
- 共享字段在编辑器中只显示一次；
- 共享字段和效能专用字段默认显示；
- 价格专用字段默认隐藏；
- 勾选“显示价格相关属性”后可编辑价格专用字段；
- 折叠不会丢失价格专用字段当前值；
- 联合重评估会同时返回价格、效能、可行性和补全后的参数。
