# V19.5 模型替换契约

## 支持版本

- 契约3.0：兼容现有演示模型；
- 契约4.0：由转换工具生成的纯JSON模型。

价格和效能必须使用同一契约版本和相同`product_code`。

## 字段角色

同一字段可以同时进入两个模型。共享字段必须使用相同编号、类型、单位和来源。价格专用必填字段必须声明可用缺失策略。

## 效能模型

效能工程没有`.pkl`时，应使用Workbook、匹配State和原重建代码导出快照。快照至少包含字段Schema、耦合模型、可行性模型、BT／UTA偏好、协议要求和历史样本。

## 价格模型

不能只复制Notebook末尾模型文件。部署包必须固化输入顺序、预处理、目标单位、模型参数、集成权重、残差区间、训练范围和训练报告。

## 安装

使用`tools/model_conversion_v19_5/validate_and_install_models.py`。安装器只替换模型JSON，不覆盖程序运行时；目标程序必须已经是完整V19.5。
