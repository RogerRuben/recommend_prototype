# V19.6 数据生命周期管理

普通操作不再直接物理删除。标签、标签规则、耦合关系、约束规则和协议数据采用：

```text
启用 → 停用/归档 → 依赖检查 → 备份 → 永久删除
```

列表页直接提供启用/停用开关。归档记录仍留在数据库，可以重新启用。永久删除仅对已停用且没有引用的记录开放，并在删除前自动备份数据库。

标签停用后，其规则仍可编辑和保存，但不参与推荐；重新启用标签后，已启用规则恢复执行。保存规则时“记录存在”与“当前启用”已分开校验。

以下内容受到额外保护：

- 当前成品不能直接停用；
- 模型必填且模型绑定的指标不能停用；
- 模型注册不能在普通页面删除；
- 模型字段契约不允许普通用户任意新增；
- 标签存在规则或协议引用时不能永久删除；
- 永久删除前自动生成SQLite备份并写入审计日志。
