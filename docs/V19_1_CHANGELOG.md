# V19.1变更记录

## 1. 静默准备生成候选

- 初始打开页面不会启动生成。
- 只有用户点击“检索历史方案”后，后台才按当前条件准备生成候选。
- 前端不展示预生成、缓存、后台任务或提速机制。
- 用户点击“生成方案”时优先复用已完成结果；未完成时显示普通等待界面并继续计算。

## 2. 最接近需求的探索方案

- 严格满足全部条件的候选仍优先返回。
- 无严格解时不再直接终止，而是返回模型可计算且最接近条件的新方案。
- 探索方案包含未满足条件、低可信度原因、模型域状态与风险说明。
- 探索方案不会被标记为严格满足需求。

## 3. 来源视图分离

- 新增“仅历史方案”“仅生成方案”“历史与生成方案”。
- 历史与生成结果不再被强制混排。
- 移除生成方案绿色卡片、绿色来源角标等视觉编码。

## 4. 数据管理中文化

- 取值类型、效能方向、标签判定方式、比较关系、耦合类型、提示级别、协议来源、模型类型、字段来源、缺失策略和契约状态优先显示中文。
- 内部代码值继续保留在数据库和接口中，避免破坏模型契约。
