# V19.3 更新说明

## 1. 非阻塞智能生成

删除全屏等待遮罩。生成期间保留当前推荐结果，用户可以继续浏览、切换视图、打开详情和修改方案。结果区只显示简洁的生成状态与进度。

生成任务绑定筛选条件指纹和请求版本。旧条件任务完成后不会覆盖用户当前的新条件结果。

## 2. 稳定生成批次

生成结果从“每个会话只有一组、后生成覆盖前生成”改为：

```text
会话
└─ 多个生成批次 batch_id
   └─ 多个候选 candidate_id
```

新批次不会覆盖旧批次。详情使用稳定批次与候选标识读取，修复部分生成方案点击后返回`not found`的问题。

## 3. 模型输出目标主动搜索

价格上限、最低效能、最低效费比和最低可行概率会主动引导邻域搜索，而不是只在生成结束后检查。

主要方法包括：

- 可调整属性的有限差分敏感度试探；
- 单属性目标改进邻域；
- 双属性协同目标改进邻域；
- 价格工程边界探测；
- 低价格区域的边界与组合候选；
- 目标差距进入候选词典序评价。

因此类似“预测价格不高于10万元”的条件能够主动推动生成器寻找低价格组合。若目标只能通过模型外推达到，系统仍计算并显示低可信提示。

## 4. 标签规则分支生成

选中标签后，系统读取DataMaster标签规则，将不同OR规则组编译成独立生成分支。规则中的技术字段、价格、效能或可行概率条件会转换为对应搜索目标。

最终候选根据实际参数和模型结果重新判定标签，并保存：

- 匹配状态；
- 命中的规则组；
- 规则明细；
- 继承或专家确认状态。

方案详情新增简洁的“生成依据”，便于解释参数与标签如何形成。

## 5. 产品表达调整

普通推荐页面改用“智能推荐”“已有参考方案”“智能生成方案”等表达，减少“历史检索”和算法设计说明。详细生成轨迹只在详情中按需展示。

## 6. 兼容性

本轮未修改：

- DataMaster八张工作表结构；
- 模型契约3.0；
- 主要业务数据库结构；
- Windows 7启动方式；
- Cloudflare登录只读模式；
- 宽表导入和专家方案库。
