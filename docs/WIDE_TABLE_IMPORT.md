# 协议宽表导入

入口：`数据管理 → 宽表导入`。

## 支持格式

- UTF-8、UTF-8 BOM、GB18030 CSV；
- 普通XLSX工作簿的第一个工作表。

XLSX解析使用Python标准库，不要求现场安装pandas或openpyxl。

## 字段识别

元数据列支持中文名称和内部名称，例如：

- 协议编号／agreement_id；
- 成品代号／product_code；
- 协议名称／agreement_name；
- 来源年份；
- 供应方类型；
- 历史价格；
- 标签。

指标列可使用：

- 数据库指标名称；
- parameter_id；
- 指标名称(单位)。

## 完整性

效能属性等于完整成品属性。模型绑定指标缺失的行会被标记为无效，不自动填0、最小值或训练均值。

价格模型如果另有价格特有字段，按照模型input_contract和“模型字段绑定”中的数据库配置值处理，不要求把价格特有字段伪装成专家可修改成品属性。

## 导入步骤

1. 下载模板；
2. 填写宽表；
3. 上传并解析预览；
4. 检查逐行错误和提醒；
5. 选择是否覆盖同编号协议；
6. 确认导入有效记录。
