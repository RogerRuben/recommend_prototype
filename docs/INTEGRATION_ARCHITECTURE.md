# V19模型一体化架构

## 运行结构

```text
浏览器
  │ 同源HTTP
  ▼
推荐系统Python进程
  ├─ 历史协议检索与标签匹配
  ├─ 用户筛选驱动的实时生成
  ├─ 完整效能／可行轮廓模型
  ├─ 独立字段契约的价格模型
  ├─ 分模型异常检测
  ├─ SQLite数据、耦合、约束和模型字段绑定
  └─ 专家方案保存、详情和宽表导入
```

现场版不拆成价格与效能两个HTTP服务，因此只有一个启动脚本和一个业务端口。

## 输入路由

```text
完整方案数据
  ├─ 完整成品属性 → 效能、可行性、生成器
  ├─ 价格模型声明字段 → 价格预测
  ├─ 数据库配置的价格专用值 → 价格预测补充输入
  └─ 数据库耦合／约束涉及字段 → 调整提示
```

价格计算使用原请求中的价格特有字段，并用效能模型标准化后的共同成品属性覆盖同名字段，避免两套字段值不一致。

## 模型生命周期

```text
离线训练
→ 导出两个版本化模型JSON
→ 契约校验
→ 原子替换并归档旧模型
→ 同步model_registry与model_input_bindings
→ 在线推荐、生成和修改重算
→ 专家反馈进入下一轮离线训练
```
