# IndustrialProtocolDemo V19.3 验证报告

验证日期：2026-07-28

## 1. 本轮目标

V19.3针对以下问题升级：

1. 智能生成期间页面被全屏等待层锁定；
2. 新生成批次覆盖旧批次，部分旧方案详情返回`not found`；
3. 价格上限等模型输出条件只参与事后筛选，不能主动引导生成；
4. 普通页面产品表达偏向“历史检索”，算法说明过多；
5. 标签如何转化成生成参数、如何判定匹配不够透明。

随包数据和模型为虚拟演示内容，不构成真实工程结论。

## 2. 实现结果

### 2.1 非阻塞智能生成

删除全屏生成遮罩，改为结果区内的简洁状态条和进度显示。任务运行时页面仍可：

- 浏览当前推荐结果；
- 切换结果范围；
- 打开方案详情；
- 修改已展示方案；
- 调整筛选条件。

任务绑定条件指纹。用户修改条件后，旧任务完成不会覆盖当前页面。

### 2.2 稳定多批次结果

每次生成形成独立`batch_id`，每份候选形成`candidate_id`。会话可同时保存多个临时批次，新任务不会覆盖旧结果。

详情接口通过稳定候选标识查询。连续生成两批后，第一批方案仍能打开和编辑。

### 2.3 价格与其他输出目标搜索

价格上限、最低效能、最低效费比和最低可行概率进入主动邻域搜索。生成器增加：

- 单属性有限差分目标试探；
- 双属性联合目标移动；
- 工程边界探测；
- 低价格边界组合候选；
- 模型输出差距词典序评价。

确定性测试条件：

```text
预测价格不高于10.000万元
最低可行概率为0
```

生成的四份候选预测价格分别为：

```text
9.965万元
9.877万元
9.964万元
9.925万元
```

所有候选均记录`max_price=10.0`为活动模型输出目标。

### 2.4 标签规则分支与判定依据

选中的规则型标签会读取DataMaster标签规则。多个OR规则组分别编译为生成分支；规则中的技术字段或模型输出字段被转换为搜索目标。

最终参数和模型结果会重新执行标签判定。每份候选保存：

- 标签是否匹配；
- 命中的规则组；
- 规则明细；
- 继承状态；
- 是否需要专家确认。

### 2.5 页面表达

普通页面统一采用：

```text
开始智能推荐
已有参考方案
智能生成方案
全部推荐方案
智能推荐结果
```

主流程删除不必要的算法说明。参考方案、改动属性、搜索动作和标签依据在详情的“生成依据”区域按需展示。

## 4. 边界说明

模型输出目标搜索只能在当前属性定义、工程边界、模型响应和允许自动调整字段构成的搜索空间内工作。如果极端目标只能通过严重外推或违反明确工程规则达到，系统会返回探索方案并显示低可信和冲突原因，不会把该结果表述为已验证的工程可实施方案。
