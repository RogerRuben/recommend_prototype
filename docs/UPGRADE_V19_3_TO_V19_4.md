# V19.3 升级到 V19.4

建议升级前备份整个目录。

## 安全升级

将升级补丁解压到V19.3目录并覆盖程序文件。补丁不包含：

- `data/`
- `models/`
- `data_master/`
- `backups/`
- `uploads/`
- `runtime/`
- `logs/`
- `exports/`

首次启动时数据库会自动迁移混合属性搜索字段。旧版防护等级定义会转为整数搜索域，旧DataMaster仍可继续导入。

## 升级后验证

先运行：

```bat
RUN_FULL_PIPELINE_TEST.bat
```

重点检查：

1. 修改生成方案属性后，右侧价格、标签、风险和经验轮廓会自动更新；
2. 设置价格不高于10万元时，系统会主动搜索防护等级、布尔功能及其他全部可调属性；
3. 原生成方案详情和专家方案库仍可正常打开；
4. 数据管理中的指标定义可看到“搜索类型”。
