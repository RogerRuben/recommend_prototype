# 独立模型服务监测与历史推荐降级说明

## 正常架构

数据管理中心不负责加载或替换价格/效能模型。它只展示：

- 两个独立 HTTP 服务的 `/health` 状态；
- 两个服务当前 `/api/v1/schema`；
- 当前业务成品代号；
- 依据当前历史成品属性生成的价格 `/predict` 和效能 `/evaluate` 示例 JSON。

示例 JSON 只用于复制、核对和接口联调，打开数据管理页面不会触发价格或效能计算。
页面明确显示“本地模型读取：已关闭”。数据库中的旧模型注册记录只作为历史审计，
不再作为服务模式的当前模型来源展示。

## 价格或效能服务异常时

任一服务无法连接或 Schema 无法读取时，主系统仍会启动，并进入“纯历史推荐模式”：

- 可以维护和切换成品业务数据；
- 可以浏览已有历史成品；
- 可以按成品属性、历史标签和历史价格筛选、排序；
- 可以打开历史成品详情，查看原始属性和历史价格；
- 不读取本地价格/效能 bundle 作为暗中回退；
- 不伪造预测价格、效能分、效费比、可行概率或风险结论；
- 暂停新方案生成、重新计算、反事实改进和基于模型的保存。

服务恢复后重启主系统，即恢复双模型计算模式。数据中心的服务监测页面刷新后会重新
探测健康与 Schema。
