# V19.6.11 最终冻结效能版变更

- 对齐 `效能评估专家版_V11_WIN7_x64_20260812_v2` 的正式冻结导出格式。
- 新增冻结模型 ZIP 的验包、冒烟评价、备份和原子安装工具。
- 效能 HTTP 服务自动识别冻结包与旧 Workbook+State 包，旧流程继续兼容。
- 成品交付打包器接受两类正式效能后端并校验内部 SHA-256。
- 新增 `/effectiveness` 操作员效能评价工作台；页面只调用效能服务。
- 工作台按模型字段动态生成数值、布尔、枚举和 IP 等级输入，参数修改后不自动计算。
- 工作台展示中心分、P10、稳健区间、可行概率、物理门控、贡献与边界/耦合风险。
- 最终专家软件自身捆绑 `openpyxl 3.1.2`；推荐系统 Win7 共享运行环境继续使用已备齐离线 wheel 且完成回归的兼容版本 `openpyxl 3.1.3`。
