# IndustrialProtocolDemo V19.1 最终验证报告

## 版本目标

V19.1围绕四项反馈完成调整：

1. 用户点击历史检索后才静默准备生成候选，前端不展示预生成提速机制；
2. 无严格可行解时仍返回最接近需求的探索方案，并明确低可信度和未满足条件；
3. 历史、生成、综合三种结果来源可以独立查看，生成方案不使用绿色标识；
4. 数据管理中的业务枚举、关系类型、操作符与状态尽可能中文显示。

## 主要通过项

### 静默准备与等待交互

- 初始打开推荐页不会启动生成；
- 只有用户点击历史检索后才启动隐藏生成任务；
- 历史结果立即返回；
- 前端源码和页面不显示“预生成”“后台提速”“缓存任务”等机制；
- 点击生成时可以复用已完成任务；
- 未完成时显示普通生成等待界面并继续计算。

### 严格方案与探索方案

- 正常条件下生成数据库中不存在的新参数组合；
- 新方案记录历史种子和实际修改属性；
- 价格与效能模型均被调用；
- 极端矛盾条件下仍返回至少一份探索方案；
- 探索方案明确标记需求匹配可信度低；
- 返回具体未满足条件，不伪装成完全满足需求。

### 结果来源

- 仅历史方案视图只返回历史协议；
- 仅生成方案视图只返回当前会话生成结果；
- 综合视图同时返回两类结果；
- 生成方案绿色卡片与绿色来源标识已移除。

### 数据管理

- 主数据工作簿可导出、解析、校验和提交；
- 主数据提交前自动备份；
- 耦合与约束变更可以立即刷新运行逻辑；
- 正向耦合、负向耦合、可行域、缺失策略、模型类型和标签判定方式等优先显示中文；
- 内部代码值仍保留，避免破坏数据库和模型契约。

### 兼容功能

- 效能模型和价格模型可使用不同字段集合；
- 价格特有属性按照模型缺失策略处理；
- 必填效能属性缺失时拒绝计算且不填0；
- 专家方案可保存并重新打开详情；
- CSV/XLSX宽表解析与写入仍可使用；
- 单进程、单端口HTTP流程通过。

## 限制说明

随包模型和历史数据为虚拟验证数据，仅证明软件链路可运行。正式业务使用前，仍需使用目标成品真实数据重新训练价格与效能模型，并由工程专家审核主数据工作簿中的标签规则、耦合关系和约束规则。
