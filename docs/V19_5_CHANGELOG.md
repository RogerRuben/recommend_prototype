# V19.5 更新说明

## 1. 价格与效能字段不再二选一

V19.5根据两个模型的字段契约计算三种角色：

```text
共享属性 = 效能字段 ∩ 价格字段
效能专用 = 效能字段 - 价格字段
价格专用 = 价格字段 - 效能字段
```

共享属性在方案中只显示一次，但数据库保留价格和效能两条模型绑定。修改共享属性后两个模型同时重算。

## 2. 方案编辑界面

- 默认显示共享属性和效能专用属性；
- 价格专用属性默认隐藏；
- 勾选“显示价格相关属性”后展开；
- 折叠不会删除价格专用字段当前值；
- 修改后继续使用V19.4的500毫秒防抖完整重评估。

## 3. 联合字段Schema

DataMaster和SQLite采用两个模型产品属性的并集。价格专用字段可以由模型契约自动补入数据库，但必填字段必须声明可部署缺失策略，避免历史协议缺字段后无法评价。

## 4. 契约4.0

运行时同时支持：

- 契约3.0：原V19.4内置演示模型；
- 契约4.0：价格和效能转换工具生成的纯JSON模型。

不允许价格与效能使用不同契约版本。

## 5. 模型转换工具

- 效能模型：Workbook＋可选State＋原模型重建代码；
- 价格模型：原始训练表重训为纯JSON集成；
- 安装前执行共享字段、缺失策略、联合推理和目标项目运行时校验；
- 成品切换必须同时提供匹配DataMaster；
- 安装失败自动回滚。
